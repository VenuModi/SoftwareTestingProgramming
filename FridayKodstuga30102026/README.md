# RobotCafe – Java Project

A simple Java café ordering program created to practise **Exceptions and Clean Code**.

## Features
- Displays a menu using an array.
- Allows customers to select products using Scanner.
- Handles invalid input using `try/catch`.
- Validates a four-digit robot code using `throw` and `IllegalArgumentException`.
- Allows customers to exit by entering `0`.

## Java Concepts Used
- Arrays and loops
- Scanner
- Methods
- Exception handling (`try`, `catch`, `throw`)
- Clean Code principles

## How to Run
Run the `RobotCafe.java` file and follow the instructions in the console.

## Purpose
A Java learning exercise focusing on writing clean, readable code and handling errors without crashing the program.
